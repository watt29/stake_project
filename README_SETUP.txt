== ไฟล์สำคัญในโฟลเดอร์ ==
  dice_bot.py         - โค้ดหลักของบอท
  config.json         - ตั้งค่า Token, Cookie, Telegram
  dice_stats.json     - สถิติสะสม (อย่าลบ!)
  run_bot.bat         - รันบอท (ดับเบิลคลิกได้เลย)
  setup.bat           - ติดตั้ง Python + dependencies
  update_session.bat  - อัปเดต Cookie/Token ใหม่

================================================
  ขั้นตอนย้ายไปเครื่องใหม่
================================================

1. COPY ทั้งโฟลเดอร์ไปเครื่องใหม่ (USB / Google Drive)
   - สำคัญ: เอา dice_stats.json ไปด้วย (มีสถิติสะสม)

2. ดับเบิลคลิก setup.bat
   - จะติดตั้ง Python และ dependencies อัตโนมัติ

3. Cookie หมดอายุทุก 6-24 ชั่วโมง ต้องอัปเดต:
   - ดับเบิลคลิก update_session.bat
   - วาง x-access-token และ cookie ใหม่

4. ดับเบิลคลิก run_bot.bat เพื่อรันบอท

================================================
  วิธีหา Cookie ใหม่ (ทำทุกครั้งที่ session หมด)
================================================

1. เปิด stake.games ใน Chrome - ล็อกอินให้เรียบร้อย
2. กด F12 เพื่อเปิด DevTools
3. คลิกแท็บ Network
4. คลิกที่ Dice game หรือ reload หน้า
5. หา request ที่ไปยัง "_api/graphql"
6. คลิก request นั้น -> Headers -> Request Headers
7. Copy ค่าของ:
   - x-access-token
   - cookie (ทั้งบรรทัดยาวๆ)
8. รัน update_session.bat แล้ววางค่าที่ copy มา

================================================
  คำสั่ง Telegram
================================================

  /menu        - เปิดเมนูหลัก (แบบปุ่มกด)
  /status      - ดูสถานะ Balance + Profit
  /profit      - สรุปกำไร/ขาดทุน
  /info        - ข้อมูล Fib Step, Streak
  /check       - ตรวจสุขภาพบอท
  /config      - ดูการตั้งค่า TP/SL
  /report      - รายงานบัญชีรายวัน
  /tp 50       - ตั้ง Take Profit 50 TRX
  /sl 30       - ตั้ง Stop Loss 30 TRX
  /stop        - หยุดบอท

================================================
  การแจ้งเตือนอัตโนมัติ
================================================

  - บอทเริ่มทำงาน       -> แจ้งพร้อมเมนู
  - ทุก 500 bets        -> รายงานสถานะ + เมนู
  - ทุก 30 นาที         -> Heartbeat
  - Step 15+            -> แจ้งเตือนความเสี่ยง
  - แพ้ติด 15+ ครั้ง    -> แจ้งเตือน
  - Bet ใหญ่ 100x+      -> แจ้งเตือน
  - ฝากเงิน 1+ TRX      -> อัปเดตต้นทุนอัตโนมัติ
  - ดึงทุนคืนสำเร็จ     -> แจ้งเตือน

================================================
  config.json (แก้ได้)
================================================

  base_bet    : เงินเดิมพันเริ่มต้น (เช่น 0.5 TRX)
  target      : เป้า Roll (48.00)
  condition   : เงื่อนไข (below/above)"
  simulate    : false=Live จริง / true=ทดสอบ
