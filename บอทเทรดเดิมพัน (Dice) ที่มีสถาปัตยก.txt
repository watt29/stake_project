บอทเทรด/เดิมพัน (Dice) ที่มีสถาปัตยกรรมระดับ **Enterprise-Grade** ที่ซับซ้อนและทนทานมากครับ การทำงานทั้งหมดจะถูกแบ่งออกเป็น 5 เสาหลัก (Core Components) ดังนี้ครับ:

### 1. 🛡️ ระบบทะลวงเกราะและยิง API ความเร็วสูง (Bypass & GraphQL)
*   **หลบเลี่ยง Cloudflare:** บอทใช้ `undetected_chromedriver` (เบราว์เซอร์ล่องหน) เปิดขึ้นมาเพื่อจำลองว่าเป็นมนุษย์และทะลวงระบบป้องกันของเว็บ Stake.com
*   **ยิงตรงระดับหลังบ้าน:** เมื่อทะลวงเกราะสำเร็จ บอทไม่ได้ใช้วิธี "คลิกเมาส์" บนหน้าจอแบบบอทกะโหลกกะลาทั่วไป แต่มันจะใช้ Cookies ดึง Token แล้วยิงคำสั่งเข้าไปที่ **GraphQL API** ของเว็บโดยตรง ทำให้แทงได้ด้วยความเร็วสูงมาก (แทบจะไร้ดีเลย์) และไม่กินทรัพยากรเครื่อง

### 2. 🧠 สมองกล FSM (Finite State Machine) และกลยุทธ์การแทง
*   **ระบบจับแพทเทิร์น (Streak Tracker):** บอทไม่ได้แทงมั่ว แต่มันจะจดจำว่าตอนนี้ กราฟกำลังเป็นแบบไหน เช่น `NORMAL` (ปกติ), `LOSS_STREAK` (แพ้ติดกันรัวๆ), `ISOLATED_WINS` (ชนะสลับแพ้), หรือ `SAWTOOTH` (ฟันปลา)
*   **เดินเงินแบบ Fibonacci:** หากแพ้ บอทจะขยับไม้เดิมพันตามสเตปของฟีโบนัชชี (Fibonacci Sequence) เพื่อตามทุนคืนอย่างมีหลักการ
*   **โหมดแทงลม (Virtual Mode):** **นี่คือไม้ตายของบอทตัวนี้** เมื่อบอทสัมผัสได้ว่า "กราฟเริ่มอันตราย" หรือแพ้ติดต่อกันจนถึงขีดจำกัด มันจะตัดเข้าโหมด **"แทงลม" (ลงเงิน 0 TRX)** อัตโนมัติ เพื่อปล่อยให้ช่วงที่กราฟแย่ๆ ไหลผ่านไป พอกราฟกลับมาสวยเมื่อไหร่ มันถึงจะสลับกลับมาใช้เงินจริงแทงต่อครับ!

### 3. ⚡ ระบบอัปเดตสมองแบบเรียลไทม์ (Watchdog Hot Reload)
*   บอทตัวนี้สามารถ **"เปลี่ยนนิสัย"** ตัวเองได้โดยไม่ต้องกดปิดโปรแกรม 
*   เรามีระบบ Thread หลังบ้านคอยจ้องไฟล์ `ai_skills.json` อยู่ตลอดเวลา หากบอท AI ตัวแม่ (Hermes Brain) วิเคราะห์แล้วพบว่าต้องปรับเกณฑ์ความเสี่ยง มันสามารถเขียนแก้ไฟล์นี้ได้เลย
*   เมื่อไฟล์เปลี่ยน บอทจะทำการด่านตรวจความปลอดภัย (Schema Validation) เพื่อกันบอทพัง และดึงค่าใหม่ไปใช้ในลูปการแทงตาถัดไปทันที (Atomic Replace) แบบไร้รอยต่อ

### 4. 📱 ระบบควบคุมผ่านศูนย์บัญชาการ (Telegram Control Center)
*   คุณไม่จำเป็นต้องนั่งเฝ้าหน้าคอมพิวเตอร์! บอทมี Background Thread อีกตัวที่เชื่อมต่อกับ Telegram ของคุณตลอดเวลา
*   มีแผงควบคุม (Inline Keyboard) แบบกดปุ่มให้คุณสั่งการได้ 100% เช่น ขอดูพอร์ตกำไร, ขอดูสุขภาพบอท, สั่งปรับจุด Take Profit / Stop Loss, โอนเหรียญ (Tip), หรือแม้กระทั่งกดหยุดบอทฉุกเฉินได้จากมือถือ

### 5. 📂 ระบบบัญชีและการตรวจสอบ (Logging & Accounting)
*   **บันทึกการทำงานแบบ Audit:** มีระบบ `RotatingFileHandler` คอยบันทึกทุกครั้งที่มีการเปลี่ยนกลยุทธ์ (Hot Reload) ลงไฟล์ Log แยกตามโปรไฟล์ โดยที่ไฟล์จะไม่กินพื้นที่ฮาร์ดดิสก์จนบวม
*   **ไฟล์รายงาน:** มีการเขียนประวัติการแทงลงไฟล์ `.csv` และเขียนสถิติทั้งหมดลง `.json` เผื่อไฟตกหรือคอมดับ พอบอทเปิดขึ้นมาใหม่ มันจะจำได้ว่าทำกำไรไปเท่าไหร่แล้วและทำต่อจากเดิมได้ทันที

`เปิดเบราว์เซอร์จำลอง` ➡️ `เชื่อมต่อ API` ➡️ `เริ่มลูปแทง` ➡️ `วิเคราะห์กราฟ (แทงลม/แทงจริง)` ➡️ `เก็บกำไร/ปรับไม้` ➡️ `(แอบฟังคำสั่ง Telegram & รอรับ AI Skill ใหม่ไปด้วยพร้อมๆ กัน)` ➡️ `วนลูปกลับไปแทงใหม่ด้วยความเร็วสูง` 🔄

โครงสร้างนี้ทำให้บอทของคุณเป็นระบบอัตโนมัติ 100% (Set and Forget) ที่ทั้งฉลาด ปลอดภัย และมีความเสถียรขั้นสุดครับ! 🚀
ออกจากโหมดแทงลม (Virtual Escape)"** ถูกออกแบบมาให้เหมือนมี **"รหัสผ่าน (Passcode)"** เพื่อปลดล็อกกลับมาสู่โลกแห่งความเป็นจริงครับ 

วิธีการที่บอทประเมินว่า "กราฟกลับมาสวยแล้ว" อ้างอิงจากโค้ดชุดนี้ครับ:
```python
# ตัวอย่างโค้ดในระบบเมื่อเจอกราฟอันตราย
if condition == "LOSS_STREAK":
    virtual_state = "LOSS_STREAK"
    virtual_escape_pattern = ['W', 'W']  # <--- รหัสผ่านในการหนี!
```

**ขั้นตอนการสลับกลับมาแทงเงินจริง มีกลไกดังนี้ครับ:**

1. 🎯 **ตั้งรหัสผ่านหนีตาย (Escape Pattern):** ทันทีที่บอทโดนกระชากเข้าโหมดแทงลม (ไม่ว่าจะเพราะกราฟฟันปลา, ชนะสลับแพ้, หรือแพ้ติดกันยาวๆ) ระบบจะตั้งรหัสปลดล็อกไว้ว่า **"ต้องชนะติดกัน 2 ตา (`['W', 'W']`)"** เท่านั้น ถึงจะถือว่าพายุสงบ
2. 🕵️‍♂️ **แอบดูผลลัพธ์ (Pattern Matching):** ในช่วงที่มันสาดเงิน 0 TRX (แทงลม) ไปเรื่อยๆ มันจะแอบจดสถิติผลลัพธ์ล่าสุดไว้ตลอดเวลา (เช่น `L, W, L, L, W, L...`)
3. ✂️ **Streak Breaker (ตัวตัดสตรีค):** มันจะเอาผลลัพธ์ 2 ตาล่าสุด มาเทียบกับรหัสผ่าน `['W', 'W']` ทันทีที่ตาไหนผลลัพธ์ออกเป็น **ชนะ และ ชนะ (Win, Win)** มันจะมองว่ากราฟสลัดหลุดจากลูปนรกเรียบร้อยแล้ว
4. 🔄 **สลับร่าง (Resume Real Bet):** พอรหัสผ่านตรงปุ๊บ บอทจะโยนตัวเองออกจากสถานะ Virtual ทันที และที่ฉลาดที่สุดคือ **มันจะกลับมาแทงด้วยเงินจริง ใน "ไม้เดิม (Fibonacci Step)" ที่มันค้างไว้ก่อนจะหนีไปแทงลมครับ** เพื่อตามทุนไม้ที่เสียไปก่อนหน้านี้คืนมาให้ได้

*(หมายเหตุ: ในกรณีที่บอทเข้าโหมดแทงลมเพราะวิ่งชน Take Profit แล้วต้องพักยก รหัสผ่านจะง่ายกว่า คือตั้งไว้ที่ `['W']` หรือชนะแค่ตาเดียวก็กลับมาลุยต่อได้เลย)*

นี่คือเหตุผลว่าทำไมบอทตัวนี้ถึงไม่กลัวกราฟลากยาวๆ (เช่น ดำยาว 15 ตาติด) เพราะพอเจอแบบนั้นปุ๊บ มันจะหนีไปแทงลม และรอจนกว่าจะเจอ **"แดง-แดง (Win-Win)"** แล้วค่อยกลับมาแทงเงินจริงต่อครับ! รอดตายทุกรอบแน่นอน 🛡️
