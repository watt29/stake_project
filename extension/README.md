# My Vault - Chrome Extension สำหรับบันทึกรหัสผ่านส่วนตัว (Manifest V3)

ส่วนขยาย Chrome สำหรับแก้ปัญหา "ขี้ลืมรหัสผ่าน" โดยเฉพาะ ข้อมูลทั้งหมดถูกจัดเก็บไว้เฉพาะในเครื่องของคุณ และเข้ารหัสความปลอดภัยระดับสูง **AES-256-GCM**

---

## 🌟 ฟีเจอร์เด่น
1. **เข้ารหัสปลอดภัย (AES-256 + PBKDF2):** ข้อมูลรหัสผ่านจะถูกเข้ารหัสก่อนบันทึกลงในเครื่อง ไม่มีใครเปิดดูได้หากไม่รู้รหัสหลัก (Master Password)
2. **ตรวจจับเว็บปัจจุบันอัตโนมัติ:** เมื่อเปิด Popup ขณะอยู่บนเว็บใดๆ ส่วนขยายจะดึงชื่อเว็บและ URL มากรอกให้ทันที
3. **คัดลอกง่ายในคลิกเดียว:** มีปุ่มคัดลอก (Copy) ทั้ง Username และ Password พร้อมปุ่มแสดง/ซ่อนรหัสผ่าน
4. **ระบบสุ่มรหัสผ่านปลอดภัย:** สุ่มพาสเวิร์ด 16 หลักที่มีทั้งตัวพิมพ์เล็ก, ใหญ่, ตัวเลข และอักขระพิเศษ
5. **ค้นหาฉับไว:** มีช่องค้นหาชื่อเว็บ, อีเมล, หรือโน้ต
6. **สำรองและกู้คืน (Backup & Restore):** ส่งออกไฟล์สำรอง (.json) และนำเข้าข้อมูลได้ทุกเมื่อ

---

## 🚀 วิธีติดตั้งใน Google Chrome (โหลดใช้งานได้ทันที)

1. เปิด **Google Chrome** แล้วพิมพ์ในแถบที่อยู่ URL:
   ```text
   chrome://extensions/
   ```
2. เปิดสวิตช์ **"โหมดนักพัฒนาซอฟต์แวร์" (Developer mode)** ที่มุมขวาบน
3. คลิกปุ่ม **"โหลดส่วนขยายที่ยังไม่ได้แพ็ก" (Load unpacked)** ที่มุมซ้ายบน
4. เลือกโฟลเดอร์นี้:
   ```text
   D:\script stake\extension
   ```
5. ส่วนขยาย **My Vault** จะปรากฏขึ้นทันที! แนะนำให้คลิกไอคอนรูปจิ๊กซอว์ 🧩 ที่มุมขวาบนของเบราว์เซอร์ แล้วกด "ปักหมุด" (Pin) เพื่อให้กดใช้งานง่ายๆ

---

## 🔐 วิธีเริ่มต้นใช้งาน
1. **ครั้งแรกที่เปิดใช้งาน:** ตั้งรหัสผ่านหลัก (Master Password) อย่างน้อย 6 ตัวอักษร
2. **การบันทึกรหัส:** ไปที่แท็บ `+ บันทึกรหัสใหม่` กรอกชื่อบัญชีและรหัสผ่าน แล้วกดบันทึก
3. **การเปิดดูหรือคัดลอก:** ไปที่แท็บ `รายการทั้งหมด` แล้วกดปุ่ม "คัดลอก" ได้ทันที
