# Review Template

Use this compact structure for log review:

1. Most likely issue
   Name the most likely bug in one sentence.

2. Why it looks that way
   Point to the exact log signals that support the diagnosis.

3. First code area to inspect
   Name the branch or phase of the round flow to read first.

4. Backup suspects
   Give one or two alternatives if the first guess is wrong.

5. Bug type
   Classify it as:
   - logic
   - persistence
   - rendering
   - resume/reconnect
