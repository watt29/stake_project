## 3. ระบบการคืนทุนตามโค้ดจริง (`content.js`)

### 3.1 ฟังก์ชันคำนวณหนี้จริง (`getCycleDeficit` บรรทัด 1896)
```javascript
function getCycleDeficit() {
    if (cycleStartBalance !== null && currentBalance !== null) {
        return Math.max(0, parseFloat((cycleStartBalance - currentBalance).toFixed(8)));
    }
    return (cycleProfit < 0) ? Math.abs(cycleProfit) : 0;
}
```
*คำนวณจากยอดเงินในกระเป๋าจริงเทียบกับทุนตอนเริ่มรอบ ไม่มีการมโนตัวเลขหนี้*

### 3.2 ฟังก์ชันคำนวณยอดแทง (`calculateCurrentBetAmount` บรรทัด 1909)
* **ไม้ตื้น ($mStep \le 4$):**
  $$\text{Bet} = \text{หนี้สะสมจริง} + \text{Base}$$
  *ผลเมื่อชนะ:* ได้กำไรสุทธิเท่ากับหนี้สะสม + 1 Base ➡️ **ล้างหนี้หมด 100% คืนทุนทันที รีเซ็ตกลับไม้ 1!**
* **ไม้ลึก ($mStep \ge 5$):**
  - เพิ่งแพ้มา: $\text{Bet} = \frac{\text{หนี้}}{2} + \text{Base}$ (ปลดหนี้ 50% ชะลอขนาดไม้)
  - ชนะตาแรกมาแล้ว: $\text{Bet} = \text{หนี้ที่เหลือ} + \text{Base}$ (ปิดหนี้ส่วนที่เหลือ)
* **กรณีชนะแล้วแพ้ (W ➡️ L):**
  - บรรทัด 4438: สั่งเปิด `closeAllNext = true` ตาถัดไปแทงปิดหนี้ทั้งหมดทันที เพื่อให้รูปแบบ ชนะ-แพ้-ชนะ สามารถคืนทุนได้จริง
